# 🌐 Kurukshetra to Campus

> **Timeless Strategy for Modern Campus Battles**  
> An interactive conflict-resolution web application translating Sri Krishna’s Peace Mission (*Udyoga Parva*) into practical teamwork solutions for students.

![Kurukshetra to Campus Banner](hero-banner.jpg)

---

## 🌟 What is this project?

In the *Mahabharata*, before the Kurukshetra war broke out, **Sri Krishna embarked on a historic peace embassy (कृष्ण-दौत्य / Krishna Doota)** to Hastinapura. Despite knowing the deep stubbornness of Duryodhana, Krishna exhausted every possible diplomatic avenue, practicing patient active listening, rational mediation, de-escalation, and offering principled concessions (even asking for merely five villages) to prevent catastrophic destruction.

**Kurukshetra to Campus** brings this ancient strategic wisdom to modern university life. When student group projects break down over missed deadlines, passive-aggressive WhatsApp messages, credit-hogging, or 50/50 decision stalemates, this application provides:

```
Mahabharata Situation ➔ Strategic Upāya Lesson ➔ Modern Campus Dilemma ➔ Actionable Next Steps
```

---

## 🚀 Key Features

1. **🎯 Interactive Conflict Solver (The Peacemaker's Compass):**
   - 12 comprehensive, curated scenarios across **Team Conflict**, **Communication Breakdowns**, **Decision-Making Stalemates**, and **Friendship/Roommate Friction**.
   - Real-time search and category filtering.
2. **📜 Authentic Epic Anchors:**
   - Accurate *Mahabharata* episodes & verses in Sanskrit (Devanagari) with English transliteration and translation.
3. **🛠️ 5-Step Actionable Checklists:**
   - Step-by-step, interactive checklists students can tick off as they mediate the dispute.
4. **💬 Ready-to-Copy Communication Scripts:**
   - Pre-written, polite, firm WhatsApp, Slack, and Email message templates with 1-click copy.
5. **🚫 Kaurava Pitfalls ("What NOT to Do"):**
   - Identifies common mistakes students make (e.g. passive-aggressive memes, rage-quitting, late-night venting).
6. **🕊️ The Krishna Doota Simulator (Interactive Roleplay):**
   - Step into the shoes of the Peace Envoy in a tense 3-stage campus project meltdown between two clashing teammates. Test your mediation score!
7. **👑 Conflict Archetype Diagnostic:**
   - 4-question interactive quiz identifying your conflict style (*Yudhishthira, Bhima, Arjuna, or Krishna*) with personalized teamwork guidance.
8. **🎼 Ambient Sound Synthesizer:**
   - Built-in, soothing meditative drone generated via the Web Audio API (no external audio files required).
9. **🖨️ Printable Action Plans:**
   - 1-click formatted print / PDF export for conflict resolution sheets.

## 💻 Tech Stack

- **HTML5:** Semantic, accessible markup with OpenGraph and SEO tags.
- **Vanilla CSS3:** Custom design system with royal dark cosmic palette (`#070A12`), gold accents (`#F59E0B`), glassmorphism, responsive grid, and smooth animations.
- **Vanilla JavaScript (ES6+):** Zero external libraries, zero frameworks, no database, no machine learning. Completely client-side and offline-ready.

## ⚡ How to Run Locally

Because this project is built with vanilla web technologies, you don't need `npm install` or complex build steps!

### Option 1: Direct Double-Click
Simply double-click `index.html` in your file explorer to open it directly in Chrome, Edge, Safari, or Firefox.

### Option 2: Python HTTP Server
Open PowerShell / Terminal in the `kurukshetra-to-campus` directory and run:

```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000`

## 🌍 How to Deploy (100% Free, Zero Setup)

### Method 1: Netlify Drop (Fastest — 30 Seconds, No Git Needed) ⭐ Recommended
1. Visit [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `kurukshetra-to-campus` folder straight into the browser window.
3. Netlify will immediately publish your website with a free, live HTTPS URL (e.g., `https://kurukshetra-to-campus.netlify.app`).

### Method 2: Vercel
1. Go to [vercel.com/new](https://vercel.com/new).
2. Drag and drop the project folder or import from your GitHub account.
3. Choose "Other" as the framework preset and click **Deploy**.

### Method 3: GitHub Pages
1. Create a repository on GitHub (e.g. `kurukshetra-to-campus`).
2. Push or upload the files (`index.html`, `style.css`, `app.js`, `hero-banner.jpg`, `logo.jpg`).
3. In your repository, go to **Settings** > **Pages**.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your site is live at `https://<your-username>.github.io/kurukshetra-to-campus`.

## 📖 The 4 Upāyas of Campus Harmony

| Upāya | Meaning | Modern Campus Application |
|---|---|---|
| **साम (Sāma)** | Conciliation & Empathetic Dialogue | Listening before reacting; grabbing coffee to understand fears. |
| **दान (Dāna)** | Fair Concessions & Win-Win Tradeoffs | Rebalancing tasks based on individual strengths; sharing credit. |
| **भेद (Bheda)** | Differentiation & Objective Analysis | Separating people from the problem; breaking deadlock with data. |
| **दण्ड (Daṇḍa)** | Firm Boundaries & Institutional Recourse | Enforcing clear rubric deadlines; escalating to Professor/TA as a transparent last resort. |
